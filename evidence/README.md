## 证据卫生：本目录做了什么处理

| 处理 | 说明 |
|---|---|
| **剔除自测污染** | 排查过程中为验证机制曾用 `sc create` 建出临时服务，产生了 **5 条** `7045` 事件。它们**不是产品行为**，已在 `scm-events.txt` 中单列并注明剔除依据 |
| **剔除无关内容** | 本机其他软件清单、系统内存统计、无关服务事件、包内随附的微软原版通用 DLL —— **一律不收录** |
| **剔除其他产品** | 名字相似但属于**另一个产品**的记录（如支付宝安全控件 `aliedit` 的服务事件）**一律不收录**；产品辨析只在 [docs/01](../docs/01-what-it-is.md) 用文字说明 |
| **脱敏** | 用户目录路径替换为占位符；主机名替换为 `<主机名>`；不包含任何账号、序列号、网络配置 |
| **不发布二进制** | 本仓库只有文本证据与脚本，**不包含任何厂商可执行文件、驱动或安装包** |

## 复核建议

1. **注册表导出**：在**你自己**的机器上先用只读命令比对，不要直接导入他人的导出（`ImagePath` 指向的是本机路径）。
2. **事件日志**：你自己的数据必然与本文不同（时间、次数），**关注的是"模式"而非"数值"** —— 例如"同一驱动服务是否被多次安装"。
3. **静态分析**：把仓库里的方法与你自己机器上的文件对照时，注意**不同版本的行为可能不同**（本文实测的是 `1.0.70.3194` / 驱动 `1.19.4.1989`）。
