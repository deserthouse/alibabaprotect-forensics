四、重要发现：没有明文的上报接口
==========================================================================================
  预期会出现的 /report、/collect、/upload 之类接口路径 —— 一条都没有（命中数 0）。
  而 HTTPS 所需的 WinHttp* 等网络 API 却有 108 处。

  ⇒ 结论只能是：上报地址不以明文存放在二进制里。
     可能来自加密配置、运行时下发，或字符串变换。
     ⚠️ 这本身不构成任何指控，只说明静态分析看不到通信目标。

==========================================================================================

  HKEY_USERS                                                                                       | WebUnion.dll

  SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon                                            | BProtect.dll

  SYSTEM\CurrentControlSet\Enum\PCI\VEN_%04X&DEV_%04X&SUBSYS_%08X&REV_%02X                         | WebServer.dll

  ⭐ 其中 `SYSTEM\CurrentControlSet\Enum\PCI\VEN_%04X&DEV_%04X&SUBSYS_%08X&REV_%02X`
     是一条【硬件枚举格式串】：按 PCI 厂商/设备/子系统 ID 拼查询路径，
     即具备采集本机硬件标识的能力。这是一条比『API 计数』更硬的证据。
